# RAQT Circuits  

Reference circuits for GHZ-based anonymous quantum transmission, 
implemented across different quantum computing platforms.

Based on: Christandl & Wehner, "Quantum Anonymous Transmissions," 
ASIACRYPT 2005. arXiv:quant-ph/0409201

## Platforms

- **Qiskit** — IBM Quantum and Aer simulator
- **NetSquid** — discrete-event quantum network simulation

## Contents

- `qiskit/ghz4.py` — GHZ-4 state preparation
- `netsquid/protocol1_anon.py` — Protocol 1 (anonymous classical bit)

## Install

pip install qiskit qiskit-aer netsquid
